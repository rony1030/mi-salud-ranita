# GymMane

GymMane reúne entrenamiento de fuerza, nutrición y seguimiento personal. La app incluye 115 ejercicios con demostraciones, registro de series y modos claro y oscuro.

La [guía de identidad](brand/Guia-de-identidad-GymMane.docx) describe el monograma, el logotipo, la paleta y la entrada animada. Los archivos maestros están en [public/icon.svg](public/icon.svg) y [public/logo.svg](public/logo.svg).

La [versión web](https://rony1030.github.io/mi-salud-ranita/) se genera en `docs/` con `node scripts/build-standalone.mjs`. Para probar la app localmente, ejecuta `npm ci` y `npm run dev`. Las pruebas se ejecutan con `npm test`.

[PLAN.md](PLAN.md), [DESIGN.md](DESIGN.md) y [PRODUCT.md](PRODUCT.md) conservan la documentación de la versión original. El catálogo y las ilustraciones se basan en [InlitX/GymMane](https://github.com/InlitX/GymMane). El arte de ejercicios se atribuye a Workout Guide y Everkinetic bajo CC BY-SA 4.0.
