# 🏋️‍♂️ GymMane GLP-1 — Entrenamiento, Nutrición y Seguimiento Semanal (Mounjaro / Ozempic)

Recreación web y Android (`.apk`) de **[`InlitX/GymMane`](https://github.com/InlitX/GymMane)** con su diseño oscuro original y todas sus funciones de gimnasio, ampliada con un módulo clínico e informativo para personas que utilizan **Mounjaro (Tirzepatida)** u **Ozempic (Semaglutida)**.

---

## 📋 Documentación del Proyecto para el Nuevo Chat

Toda la arquitectura y especificación para reconstruir la aplicación de forma 100 % profesional (sin ícono ni nombre de ranita, siguiendo fielmente el diseño de **GymMane**) está documentada en estos tres archivos del repositorio:

1. 📄 **[`PLAN.md`](./PLAN.md)** — **Plan Maestro de Construcción paso a paso** (Estructura de las 5 pestañas de GymMane, integración GLP-1, activos reutilizables y secuencia de compilación Web + APK).
2. 🎨 **[`DESIGN.md`](./DESIGN.md)** — **Sistema de Diseño Dark Mode de GymMane** (Paleta `#0D0D0F` / `#16161A` / `#FF6B35` / `#10B981`, tipografía tabular, anillos de macros y mapa anatómico).
3. 📦 **[`PRODUCT.md`](./PRODUCT.md)** — **Especificación Funcional Completa** (Los 115 ejercicios animados, las 8 rutinas de GymMane + 4 rutinas GLP-1 anti-flacidez, semáforo de alimentos, rotación de inyecciones y control de síntomas).
